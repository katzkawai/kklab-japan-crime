- 特殊詐欺の認知件数・被害額：2016–2025年。SNS型投資・ロマンス詐欺：2023–2025年。
- 47都道府県の認知件数・人口10万人当たり認知件数：2016–2025年。

## 読み方と制約

- 認知件数は警察が把握した事件数で、未届け・未把握の被害を含む犯罪の実数ではありません。
- 「刑法犯」は警察統計上の区分です。交通関係の業務上過失致死傷等を除き、一部の特別法の罪を含みます。薬物等の特別法犯、交通犯罪、相談件数等は本ページの集計対象外です。
- 検挙率＝当年の検挙件数÷当年の認知件数。検挙には前年以前に認知した事件が含まれ、当年の事件の解決割合とは異なります。
- 殺人は未遂等を含む事件数で、死亡者数ではありません。
- 性犯罪は2017年・2023年の法改正をまたぎ、旧罪名を含む系列です。2023年から性的姿態撮影等処罰法の罪も計上されています。
- 2025年の人口当たり指標は2024年10月1日現在の人口を分母とする警察庁公表値です。都道府県別の指標は通勤・観光等の流入を調整せず、個人の被害確率を表しません。
- 1972年以前の数値は、1972年5月14日以前の沖縄県の該当分を含みません。
- 特殊詐欺にはキャッシュカード詐欺盗を含みます。詐欺・窃盗等と重なる切り口なので、刑法犯総数等に足し合わせません。2023年のSNS型ロマンス詐欺は調査対象が異なります。
- 増減の原因はこれらの集計値のみから断定できません。

## データと再現性

| パス | 内容 |
| --- | --- |
| `data/raw/` | 取得した警察庁のCSV・Excel・PDF・凡例の原本 |
| `data/raw-manifest.json` | 原本URL・取得日・SHA-256 |
| `data/*.csv` | 整形したUTF-8のデータ |
| `data/reviewed.json` | 数値・出典・定義・変換手順を含むスナップショット |
| `scripts/prepare_data.py` | Python標準ライブラリのみで抽出・整形・照合 |
| `app/src/content/dashboard/` | Reactの表示と操作 |
| `docs/` | 検証済みのGitHub Pages公開用ファイル |

```bash
python3 scripts/prepare_data.py
python3 scripts/verify_site.py
python3 -m http.server 4173 --directory docs
```

`http://localhost:4173/` で表示できます。データの再生成にはネットワーク接続やAPIキーは不要です。自動取得・自動更新は行いません。

変換時には、和暦を西暦に変換し、欠測を0で埋めず、各表の集計粒度を保持します。詐欺被害額はCSVで指数表記による丸めがあったため、Excelの正確な円単位の数値を使用しています。

検証は、白書と長期統計の73年×4指標（292値）の一致、各年の6罪種・47都道府県の合計と全国総数の一致、全807レコードの公開CSVとの一致、原本・公開ファイルのハッシュを確認します。

ページを編集した後のビルド手順は [BUILD.md](BUILD.md) を参照してください。初回作成時にChromeでPC幅1440px・スマートフォン幅390pxの4画面を確認しています。
